# Contact Manager CLI

A **command-line application** for managing contacts, developed in C# with .NET.  
It allows you to add, edit, delete, view, and organize your contacts efficiently.

---

## Requirements

- **.NET 9.0** or later  
- **Visual Studio 2022** or newer (or any compatible IDE)

---

## Running the Application

1. Clone or download the repository to your machine.  
2. Open the solution file `Microsoft.ContactManager.CLI.sln` in Visual Studio.  
3. Build the project and run it using the **Run** button or **F5**.

The application will start in the console with an interactive menu.

---

## Features

- Add, edit, and delete contacts  
- List all contacts  
- Search contacts by name or email  
- Filter contacts by creation date  
- Data is automatically saved to `contacts.json` but you can save it automaically if you want
